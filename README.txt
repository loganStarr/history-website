HISTORICAL WEBSITE TEMPLATE

Open index.html in your browser to preview. Edit HTML files in VS Code. Change style.css to customize all pages. Replace images/banner.svg and images/historical.svg with your own images, updating references in CSS and HTML if filenames change. The graphics are placeholders, not historical photographs.

DEPLOY TO VERCEL
Upload the contents of this folder to a GitHub repository. In Vercel choose Add New Project and import that repository. Framework preset: Other. No build or install command is needed. Use the folder containing index.html as root. Deploy. Alternatively use the Vercel CLI from this folder (npx vercel) and follow prompts.

All pages use plain HTML and CSS. No dependencies or backend needed.
